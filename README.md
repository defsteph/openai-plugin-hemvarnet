# Hemvärnet

Inkluderar Hemvärnets Kunskapsbank-skill med 14 publikationer som sökbara textreferenser: Hemvärn, bataljon, kompani, pluton/grupp, Direktiv Hemvärn, grundläggande soldat- och sjömansutbildningar, förplägnadstjänst, personaltjänst, stabstjänst och transport av farligt gods.

Källförteckning, utgåvor och sökanvisningar finns i [skillen](skills/hemvarnet-knowledge-center/SKILL.md). Textfilerna bevarar PDF-sidindelningen med sidbrytningstecken (`\f`); bilder och tabellayout kan behöva kontrolleras i originalet.
